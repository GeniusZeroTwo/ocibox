# UI 界面设计与交互硬性规范 (UI Design Guidelines)

> 本规范由用户针对历史 UI 粗糙、不协调、冗余文字与表情滥用问题严肃纠正沉淀，后续所有涉及前端界面的开发必须严格遵守。

---

### 1. 绝对极简主义（Minimalism & High Signal-to-Noise Ratio）
* **拒绝唠叨文案**：绝不添加大段说明文字、分步指引段落或多余的辅助标签。
* **高信息密度与纯粹专注**：操作弹窗与浮动控件优先采用“纯图标 / 极简短标题 + 纯图标动作按钮”。
* **浮动与辅助按钮去文字化**：顶部或角落的浮动按钮、切换按钮仅保留按钮本身与核心矢量图标，禁止附带长条文字胶囊或打扰视线的浮层文字。

---

### 2. 严禁使用 Emoji 作为界面图标（No Emoji Icons）
* **严禁滥用 Emoji**：禁止在按钮、输入框前缀、弹窗标题、空状态或列表操作中使用 Emoji（如 🚀, ✈️, 🛡️, 💡, 🔐, 🗑️, 📅, ⚡, 🔄 等）。
* **全面使用统一矢量 SVG**：
  * 采用干净现代的线性矢量 SVG（推荐 Feather / Lucide 风格）。
  * 保持统一的描边宽度（stroke-width: 2 或 2.2）、描边端点（round）与视口比例（viewBox="0 0 24 24"）。

---

### 3. 像素级尺寸协调与几何对齐（Alignment & Coordination）
* **输入框与按钮的 1:1 绝对对齐**：
  * 水平并排的输入框容器与提交按钮，其高度必须像素级一致（如统一 42px 或 44px），圆角必须完全相同（如统一 10px 或 12px）。
  * 严禁出现输入框与按钮高度错位、圆角不搭、字体基线上下偏离。
* **竖向组件中轴严格对齐**：
  * 纵向排列的浮动控制按钮（如切换主题与通行密钥管理），必须基于垂直中轴线严格居中对齐（`align-items: center`），且采用相同的几何外形与尺寸（如 44px 纯圆）。
* **关闭按钮规范**：
  * 严禁直接使用 HTML 纯文本字符 `×`。
  * 必须使用标准矢量 SVG 交叉线关闭图标，包裹在具圆润反馈的专用微交互按钮内。

---

### 4. 样式隔离与全局样式防穿透（CSS Style Isolation）
* 项目内存在全局侵入性选择器（如 `button:not(...)` 对实心绿色渐变的强制重写）。
* 编写任何自定义独立按钮时，必须在全局选择器排除列表中显式排除，或通过专用高优先级类名保证尺寸、背景渐变、微光投影与圆角不被破坏。
